# 本地技能与扩展边界

> 权威范围：当前 SKILL.md 格式、加载、使用与未来分发门槛。
> MCP 协议/进程见 [MCP](../mcp/mcp-integration.md)，权限见 [工具权限](../security/tool-permission.md)。

## 1. 当前是声明内容，不是插件平台

核心服务从配置的受限目录扫描 `*/SKILL.md`，检查路径、大小和元数据，通过 `skill list/read` 提供给模型。UI/API 只读显示真实加载清单，新增文件后重启核心服务。

- 当前支持 `instruction` 与 `workflow` 两个 kind，均不执行包内代码；workflow 是流程说明，不是持久 DAG。
- 内置工具是受信内置代码，不通过第三方技能包注册。
- 受信可执行扩展目前通过部署配置的 stdio MCP Server，不通过 SKILL.md entrypoint。
- LangGraph 路径已接声明式 skill 读取；目录摘要进入稳定前缀，正文按需加载。可调用能力仍受已迁工具与 PermissionPolicy 限制，见 [智能体运行时设计](../../design/AgentRuntime.md)。

## 2. 当前文件格式

```markdown
---
name: research-brief
description: 生成带来源的研究简报。
version: 1.0.0
kind: instruction
---
明确目标和输入；读取一手来源，区分事实与推断；
输出带引用的简报，遇到权限或资料缺口时停止并说明。
```

当前 description 与正文不能为空；版本未写时默认 `1.0.0`，kind 未写时默认 `instruction`，name 可从目录名获得。可选 `parameters_schema` 必须是对象；这些元数据不是自动执行协议。实际合法名称/大小与路径限制以 `skill_registry.py` 为准。

正文应说明适用/不适用条件、输入/交付物、步骤、停止与失败处理、依赖能力。目录描述应短；不要把全文塞入固定提示词。

技能不包含凭证、隐藏系统提示、索取隐藏思维链或绕过权限的要求。声明“需要某工具”仅表示依赖，不表示该工具已安装、已迁移或获批。

## 3. 安全与资源

读取内容按不可信上下文处理，权限由服务端规范化参数和策略决定。技能不改变 hard-deny，不允许扩大文件、网络、Shell 或敏感凭证范围。

MCP 子进程生命周期独立于技能内容，仍由核心服务管理；不要因为同属“扩展”统一成新的插件生命周期、DI 或能力框架。

## 4. 未交付的扩展分发

目前没有远程 import/install、签名、依赖解析、不可变 SkillVersion、工作区 Grant、升级/回滚或自动卸载。移除先前完整目标 Manifest/状态机，避免其被当作当前格式。

只有用户确需分享/安装个人定制流程时才调查成熟分发实现，并比较复用成本。不为小规模本地文件新增注册中心、发布者平台或包管理器。

若确需执行型分发，最低约束为：

- 安装前验证来源、摘要值、内容与能力，失败不执行入口。
- 入口用 command/args 而非 shell 字符串；依赖确定且不得隐式扩大权限。
- 用户配置与不可变内容分离，只存凭证引用；版本更新不覆盖用户配置。
- 能力增加要重新批准，撤销凭证不因回滚恢复。
- 停用/卸载阻止新调用并等待或取消活动调用，停止所属进程并保留必要审计。
- 不混淆包版本、授权和运行进程状态。

这些是未来安全门槛，不是现有 Schema/API；只有真实需求、后端闭环与测试后才新增格式，届时在本页维护唯一规范。
