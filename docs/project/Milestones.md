# NanamiGopher — 版本规划

## 概览

NanamiGopher 在 16 周的开发周期内发布 4 个主要版本，每个版本对应一个明确的交付目标和用户群体。

| 版本 | 代号 | 发布时间 | 目标用户 | 成熟度 |
|------|------|---------|---------|--------|
| v0.1 | MVP | Week 2 | 内部测试 | 技术验证 |
| v0.5 | Beta | Week 6 | 早期采用者 | 体验打磨 |
| v1.0 | GA | Week 12 | 生产用户 | 功能完整 |
| v1.5 | Release | Week 16 | 大众用户 | 生态就绪 |

---

## v0.1 — MVP（Week 2）

> **目标**：验证核心技术栈，展示最小可用功能。

### 版本说明

这是 NanamiGopher 的第一个可运行版本。它证明了 Go API Gateway + Python Agent Core 的混合架构可行，并展示了基础的 AI 对话能力。

### Feature List

#### 核心功能

- [x] Go API Gateway（Gin）
  - [x] RESTful 路由框架
  - [x] CORS 中间件
  - [x] JWT 认证中间件
  - [x] 基础健康检查接口 `/health`
- [x] Python Agent Core
  - [x] LLM 调用封装（OpenAI API）
  - [x] 工具调用（Tool Calling）接口
  - [x] 消息格式标准化
- [x] 对话引擎
  - [x] 单轮对话
  - [x] 多轮对话（会话上下文管理）
  - [x] 会话创建/删除/列表
- [x] 工具系统
  - [x] 工具注册中心
  - [x] 动态工具发现
  - [x] 工具参数校验
- [x] 记忆系统
  - [x] 短期记忆（会话内上下文窗口）
  - [x] 最大 Token 限制管理
- [x] 权限系统 v1
  - [x] 用户注册/登录
  - [x] 基础角色（admin / user）
  - [x] API 级别的权限拦截
- [x] Example 插件 × 2
  - [x] Plugin 模板（Hello World）
  - [x] Plugin 加载机制
  - [x] Example: 天气查询工具
  - [x] Example: 代码格式化器
- [x] 前端基础
  - [x] Vue 3 + Vite 项目初始化
  - [x] 对话界面（消息列表 + 输入框）
  - [x] 用户登录页面

### 已知限制

- 仅支持单一 LLM 后端（OpenAI）
- 无流式输出
- 无本地模型支持
- 无持久化记忆
- 无错误处理机制
- 前端仅为概念验证

---

## v0.5 — Beta（Week 6）

> **目标**：打磨核心体验，让用户愿意日常使用。

### 版本说明

v0.5 是第一个面向早期采用者的版本。它引入了多对话管理、流式输出、本地模型支持等关键能力，显著提升了用户体验。

### Feature List

#### v0.1 增量

- [x] 多对话管理
  - [x] 同时打开多个对话窗口
  - [x] 对话列表侧边栏
  - [x] 对话搜索
  - [x] 对话归档
- [x] 流式输出
  - [x] SSE 流式传输
  - [x] WebSocket 双向通信
  - [x] 打字机效果前端组件
- [x] 错误处理系统
  - [x] 统一错误码体系
  - [x] 用户友好的错误提示
  - [x] 错误日志记录
- [x] 本地模型支持
  - [x] Ollama 集成
  - [x] 模型选择器（云端 / 本地）
  - [x] 本地模型能力说明
- [x] Telemetry 基础版
  - [x] 对话数量统计
  - [x] 平均响应延迟
  - [x] Token 消耗统计
- [x] Playwright 集成
  - [x] Agent 可发起浏览器请求
  - [x] 网页内容抓取
- [x] OCR 模块
  - [x] 中文图片文字识别
  - [x] 截图 → 文字 → 工具输入 链路
- [x] Electron 桌面端
  - [x] 项目初始化
  - [x] 基本窗口布局
  - [x] 系统托盘集成
- [x] 前端完善
  - [x] 多对话标签页
  - [x] 设置页面
  - [x] 用户中心

### 已知限制

- DSL 工作流尚未实现
- 无可观测性面板
- 无 Plugin 热加载
- 无长期记忆
- 无团队协作功能
- 前端未完全响应式

## v1.0 — GA（Week 12）

> **目标**：功能完整，达到生产可用标准，面向正式用户发布。

### 版本说明

v1.0 是 NanamiGopher 的第一个正式版本（General Availability）。它包含了完整的 Agent 编排能力、可观测性平台、长期记忆系统和安全的 Plugin 架构。

### Feature List

#### v0.5 增量

- [x] DSL 工作流引擎
  - [x] YAML/JSON 工作流定义
  - [x] 条件分支（if/else）
  - [x] 循环（for/while）
  - [x] 变量传递
  - [x] 工作流执行器
  - [x] 工作流可视化编辑器（基础版）
- [x] 多 Agent 架构
  - [x] Master Agent（任务分解）
  - [x] Worker Agent（任务执行）
  - [x] Agent 间通信协议
  - [x] 结果聚合
- [x] 可观测性完整版
  - [x] OpenTelemetry 集成
  - [x] 链路追踪（Trace ID 传播）
  - [x] 指标面板（Prometheus + Grafana）
  - [x] 日志聚合（结构化日志）
  - [x] 告警规则
- [x] Plugin 架构
  - [x] 热加载机制
  - [x] 沙箱隔离（容器化执行）
  - [x] 版本管理
  - [x] Plugin 市场（基础版）
  - [x] 权限绑定
- [x] SubAgent 系统
  - [x] 主 Agent 创建子任务
  - [x] 子任务优先级调度
  - [x] 结果回传机制
  - [x] 超时和重试
- [x] Inspector
  - [x] 实时 Agent 状态查看
  - [x] 工具调用链可视化
  - [x] 记忆内容浏览
  - [x] 执行时间线
- [x] 长期记忆系统
  - [x] ChromaDB 向量存储
  - [x] 语义检索
  - [x] 记忆摘要生成
  - [x] 跨会话记忆共享
- [x] 文件存储系统
  - [x] 文件上传/下载
  - [x] 文件版本控制
  - [x] 文件搜索
- [x] 前端完善
  - [x] 工作流编辑器
  - [x] Inspector 面板
  - [x] 可观测性仪表盘
  - [x] Plugin 管理界面

### 已知限制

- 无 Skill 市场（待 v1.5 实现）
- 无 Team 协作功能
- 安全加固尚未完成
- 性能优化未达生产级
- 文档体系不完整

### 发布说明

这是 NanamiGopher 的第一个正式公开发布版本。建议在以下环境部署：

- 操作系统：Ubuntu 22.04 LTS / macOS Sonoma
- Go：1.22+
- Python：3.12+
- Node.js：20+
- 数据库：SQLite（开发）/ PostgreSQL（生产）
- 缓存：Redis 7+
