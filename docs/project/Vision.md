# NanamiGopher — 项目愿景

> 状态：Current（产品方向，不代表功能已经交付）

## 产品愿景

**让每一位中文开发者拥有自己的 AI 工作助手。**

NanamiGopher 是一个以中文优先的 AI 工作助手，构建于 Claude Code 生态理念之上，采用 LangChain + LangGraph + MCP（Model Context Protocol）的核心架构。它不仅仅是一个代码补全工具，而是一个能够理解上下文、自主编排任务、管理记忆的完整 AI 代理平台。

我们的目标是打造一款开箱即用、高度可定制、面向中文开发场景深度优化的智能助手——从日常编码到复杂的多步骤任务编排，从单文件修改到跨仓库级重构，NanamiGopher 都能以自然语言交互的方式，成为开发者最可靠的工作伙伴。

## 核心价值主张

### 1. 中文优先，深度适配
- 原生支持中文指令理解和生成
- 针对中文技术文档、中文注释、中文社区资源做专项优化
- 中文搜索、中文 OCR、中文语境下的错误提示

### 2. 真正的 AI 代理，而非简单的代码补全
- 基于 LangGraph 的状态机编排，支持多步骤复杂任务
- 内置记忆系统（短期上下文 + 长期向量存储），持续学习用户偏好
- MCP 协议扩展，可接入任意外部工具和 LLM 服务

### 3. 全栈一体化架构
- Go 高性能 API 网关 + Python 灵活 Agent 核心 + Vue 3 响应式前端
- 桌面端（Electron）+ Web 端双平台覆盖
- REST / gRPC / WebSocket / MCP 多协议支持

### 4. 轻量、可嵌入、个人部署
- SQLite 作为默认存储，无需外部数据库依赖
- 1 人全栈即可开发和维护的架构复杂度
- 支持本地模型运行，数据不出本机

## 目标用户画像

| 用户类型 | 描述 | 核心需求 |
|---------|------|---------|
| **中文独立开发者** | 单人负责全栈开发的个人开发者 | 快速原型、自动测试、文档生成 |
| **中小团队工程师** | 5-50 人技术团队的成员 | 代码审查辅助、重构建议、知识传承 |
| **AI 探索者** | 对 Agent 框架、MCP 协议感兴趣的技术爱好者 | 可扩展的 Agent 平台、Skill 开发、DSL 工作流 |
| **数据安全敏感用户** | 需要本地化部署、数据不出机的企业用户 | 本地模型支持、私有化部署、审计日志 |

## 差异化优势

### vs Claude Code

| 维度 | Claude Code | NanamiGopher |
|------|------------|--------------|
| 语言支持 | 英文优先 | **中文优先**，深度中文适配 |
| 架构开放性 | 封闭生态 | **开源架构**，MCP 协议可扩展 |
| 本地化部署 | 不支持 | **完全支持**本地部署 |
| 模型灵活性 | 仅限 Claude | 支持多种 LLM（含本地模型） |
| 自定义程度 | 有限 | **DSL 工作流 + Skill 生命周期 + SubAgent** |

### vs Cursor

| 维度 | Cursor | NanamiGopher |
|------|--------|--------------|
| 交互方式 | IDE 扩展为主 | **桌面应用 + Web 应用** 双形态 |
| 任务编排 | 单步编辑 | **多 Agent 协作 + 状态机编排** |
| 记忆能力 | 有限上下文 | **短期 + 长期记忆系统** |
| 扩展生态 | 扩展商店 | **MCP 协议 + Skill 市场** |

### vs GitHub Copilot

| 维度 | GitHub Copilot | NanamiGopher |
|------|---------------|--------------|
| 核心能力 | 代码补全 | **完整 AI 代理，自主执行多步骤任务** |
| 架构 | 黑盒服务 | **透明 Agent 链，可观测、可调试** |
| 定制化 | 低 | **高（DSL、Skill、自定义 Agent）** |
| 数据存储 | 云端 | **本地优先，隐私可控** |

## 设计哲学

### 1. 渐进式复杂性
- 基础功能（对话 + 工具调用）开箱即用，零配置
- 高级功能（DSL 工作流、多 Agent 编排）按需启用
- 用户可以从"简单聊天"平滑过渡到"复杂 Agent 编排"

### 2. 透明可观测
- 每一步 Agent 决策都有迹可循
- 完整的 Telemetry 链路追踪
- Inspector 工具支持实时查看 Agent 内部状态

### 3. 安全优先
- 沙箱化的工具执行环境
- 细粒度的权限控制系统
- 敏感操作需要用户确认

### 4. 中文原生
- 不是翻译，而是从底层架构层面支持中文
- 中文语境的意图理解优于英文直译
- 中文技术社区的知识和实践内嵌于系统

### 5. 开放生态
- MCP 协议确保与第三方工具的互操作性
- 统一 Skill 生命周期允许第三方在显式授权范围内扩展能力
- 核心代码开源，社区共治
