- 默认工作区改为安装根目录下的 `.workspace`（源码运行时为项目根目录下的 `.workspace`），启动时创建；桌面/开发启动器统一根路径，保留显式环境变量与 YAML 工作区配置，不搬动旧文件或数据库。安装目录不可创建工作区时明确报错，不自动提权或换目录；跨平台安装运行尚未验收。

### 变更

- 模型窗口解析改为离线资料优先、后台刷新：复用 models.dev 生成的容量快照，不因首次联网失败让已知模型全部未知；目录声明的别名 / 唯一原始模型关系可用于关联资料，调用 ID 不改写。Gateway 和 Core 补齐中转站 `limit.context` / `max_input_tokens` 及别名列表解析，Anthropic 协议中转站也可读取服务声明容量。聊天仪表移除容量来源、获取时间和部署说明，只保留数字、用量、预算及必要的失败反馈；不照搬通用 256K 默认。新增离线快照更新脚本和上游许可，无新依赖。仅做源码人工审阅与公开目录获取，未运行测试、构建、类型检查或真实模型验收，未操作 Git 或启停服务；模型请求的代理策略保持不变。

- 小窗口请求不再一律预留 4096 tokens 输出：按已知容量缩放本次请求上限，保留显式思考预算的必要下限，预算检查、压缩阈值和 Provider 参数一致；精简原生规划说明而不改工具 schema 或权限审批。输入框下方直接显示「已用 / 窗口容量」及百分比，详情区区分配置输出上限与本次输出预留。已缓存模型按目录 TTL / 退避重新获取容量，首次失败不会使其永久未知；未知容量提供填写入口，不用固定容量兜底。本次仅完成源码修改和人工审阅，未运行测试、构建或真实模型验收，未操作 Git 或启停服务。

- 补齐通用模型窗口资料链路：兼容 / 中转接入不再排除 SDK 模型资料；复用 models.dev 公共目录补充精确模型容量，Ollama 通过官方 SDK 获取已加载窗口或模型资料。目录容量按配置身份由 Core 保留，并用于压缩输入预算；前端刷新、切会话及获取失败时保留已知容量和来源，但不复用其他会话的用量。没有本会话用量不显示假 0%，未知模型不套固定窗口。本次未运行测试、构建或真实服务验收。

- 兼容模型服务的流式缓存字段（包括无正文的用量尾包）接入现有 LangChain 元数据聚合；只保存服务实际报告的读取、写入和未命中，不估算命中数。缓存统计显示回执覆盖数，缺少请求回执或缓存字段时保留已报告用量并明确提示，不再把部分请求的比例当作整个对话的命中率；不一致的数据不显示百分比。中英文同步。本次完成源码修改，未运行测试、构建或真实服务验收，需重启 Core 并刷新前端后使用新逻辑；旧回执中已丢失的缓存字段不会补造。
- 模型选择和空白对话可直接读取窗口容量，复用 Core 的解析和客户端；详情补齐输入预算、输出预留及压缩阈值。兼容有配置身份的旧回执，不串用其他会话用量；缺失容量保留原因和重试。设置页增加逐模型的可选已知容量，目录缺失数据不再清空保存值。容量已知时不再套用 32000 的统一输入上限；未知时不伪造预算/阈值。明确超限且未输出内容时复用原生摘要做一次恢复，失败不替换历史；固定指令超预算单独提示。仅完成源码与 protobuf 绑定接入，未运行测试、应用构建或真实服务验收，需用户重启 Gateway/Core 后使用新接口。
- 输入区移除常驻快捷键说明；设置中可选择 Enter 发送或换行，Shift+Enter 始终换行，Ctrl/Cmd+Enter 可发送。首次聚焦短暂提示当前规则并记住已展示状态；队列和停止操作保持原样。清理工具原始模型说明、权限迁移与外观实现说明，保留操作帮助和风险提示；中英文同步。本次未运行测试或构建，待界面验收。
